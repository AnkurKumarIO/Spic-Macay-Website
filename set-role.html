Assign or revoke roles for users. Signed in as —.

How roles work: Roles are stored as custom claims on Firebase Auth tokens. Setting a role here calls a Firestore-based lookup — the actual custom claim must be set via the Firebase Admin SDK (server-side). This page records the intended role in a userRoles Firestore collection which your backend or a Cloud Function should sync to Auth custom claims.

Quick setup without Cloud Functions: Use the Firebase Console → Authentication → find the user → copy their UID → run the Admin SDK snippet below once.

Apply Roles via Admin SDK

Run this Node.js snippet once (e.g. in a Cloud Function or local script) to actually set the custom claim on Firebase Auth. Without this step, the Firestore rules based on request.auth.token.role will not take effect. 

const admin = require('firebase-admin');
admin.initializeApp();

// Set volunteer role
await admin.auth().setCustomUserClaims(USER_UID, { role: 'volunteer' });

// Set admin role
await admin.auth().setCustomUserClaims(USER_UID, { role: 'admin' });

// Remove role
await admin.auth().setCustomUserClaims(USER_UID, {});

// The user must sign out and sign back in for the claim to take effect.

Find the UID in Firebase Console → Authentication → Users → click any user.
